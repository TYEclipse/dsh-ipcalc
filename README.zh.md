# dsh-ipcalc（中文简介）

面向 DeepSeek Harness (dsh) 的 IP 与子网数学工具箱：五个纯本地计算工具，
**零运行时依赖、无任何网络访问**，专门解决大模型心算子网边界常出错的问题。

## 工具一览

| 工具 | 功能 |
|------|------|
| `ipv4_subnet` | 解析 IPv4 CIDR（支持 `a.b.c.d/前缀`、点分掩码如 `/255.255.255.248`、裸地址按 /32）→ 网络号、广播地址、子网掩码、反掩码、可用主机范围与数量、整数形式、IANA 分类 |
| `ipv4_summarize` | 把一组 IPv4 地址/网段归并为最小覆盖 CIDR 列表（相邻合并 + 对齐超网），如 4 个 /24 → 1 个 /22 |
| `ip_parse` | 校验、规范化（RFC 5952）并分类任意 IPv4/IPv6 地址，识别 `::ffff:a.b.c.d` 内嵌 IPv4 形式 |
| `ipv6_subnet` | IPv6 子网计算：128 位 BigInt 精确算术 → 网络地址、首末可用主机、精确地址数（十进制字符串，超出 2⁵³ 不失真）、RFC 5952 规范形、IANA 分类 |
| `ip_match` | 判定裸 IP（v4/v6）是否属于某 CIDR 网段，输出规范化网段范围；版本错配明确报因 |

## 安装

```bash
dsh plugin --profile <你的 profile 名> add github:TYEclipse/dsh-ipcalc
```

## 示例

```
ipv4_subnet("192.168.1.25/24")
→ 网络 192.168.1.0/24，掩码 255.255.255.0，广播 192.168.1.255
  主机范围 192.168.1.1 – 192.168.1.254（256 个地址中 254 个可用）

ipv6_subnet("2001:db8:1234:5678::1/64")
→ 网络 2001:db8:1234:5678::/64
  范围 2001:db8:1234:5678::1 – 2001:db8:1234:5678:ffff:ffff:ffff:fffe
  （18446744073709551616 个地址中 18446744073709551614 个可用）

ipv6_subnet("::/0")
→ 全 IPv6 空间：340282366920938463463374607431768211456 个地址

ipv6_subnet("fe80::1/127")
→ RFC 6164：点对点链路上两个地址均可用

ip_match("192.168.1.5", "192.168.1.0/24") → INSIDE
ip_match("2001:db8::5", "2001:db8::/32") → INSIDE
ip_match("192.168.1.5", "2001:db8::/32") → valid:false（版本错配，明确报因）
```

## 语义要点

- IPv4 数学用 32 位整数精确算术（无位运算溢出风险）；IPv6 子网数学用 128 位 BigInt，地址数超 2⁵³ 时以十进制字符串返回，绝不失真。
- `/31` 遵循 RFC 3021、IPv6 `/127` 遵循 RFC 6164（点对点两地址可用）、`/32` 与 `/128` 视为单主机。
- IPv6 规范化遵循 RFC 5952（小写、去前导零、最长零段压缩为 `::`）。
- 分类依据 IANA 特殊用途地址注册表（私网/环回/链路本地/CGNAT/文档段/组播/保留段/全局 等）。
