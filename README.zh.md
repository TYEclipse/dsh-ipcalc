# dsh-ipcalc（中文简介）

面向 DeepSeek Harness (dsh) 的 IP 与子网数学工具箱：三个纯本地计算工具，
**零运行时依赖、无任何网络访问**，专门解决大模型心算子网边界常出错的问题。

## 工具一览

| 工具 | 功能 |
|------|------|
| `ipv4_subnet` | 解析 IPv4 CIDR（支持 `a.b.c.d/前缀`、点分掩码如 `/255.255.255.248`、裸地址按 /32）→ 网络号、广播地址、子网掩码、反掩码、可用主机范围与数量、整数形式、IANA 分类 |
| `ipv4_summarize` | 把一组 IPv4 地址/网段归并为最小覆盖 CIDR 列表（相邻合并 + 对齐超网），如 4 个 /24 → 1 个 /22 |
| `ip_parse` | 校验、规范化（RFC 5952）并分类任意 IPv4/IPv6 地址，识别 `::ffff:a.b.c.d` 内嵌 IPv4 形式 |

## 安装

```bash
dsh plugin --profile <你的 profile 名> add github:TYEclipse/dsh-ipcalc
```

## 示例

```
ipv4_subnet("192.168.1.25/24")
→ 网络 192.168.1.0/24，广播 192.168.1.255，可用 192.168.1.1–192.168.1.254（254 个）

ipv4_summarize(["10.0.0.0/24", "10.0.1.0/24", "10.0.2.0/24", "10.0.3.0/24"])
→ ["10.0.0.0/22"]

ip_parse("::ffff:192.168.1.1") → IPv6，ipv4_mapped，内嵌 192.168.1.1
```

## 语义约定

- 全部使用 32 位整数的精确 double 运算（2³² 以内精确可表示），无位运算溢出风险
- /31 遵循 RFC 3021（两个地址均可用，点对点链路）；/32 视为单主机
- IPv6 规范化遵循 RFC 5952：小写、去前导零、压缩最长零段（并列取最左）
- 分类按 IANA 特殊用途注册表：IPv4 区分未指定/广播/环回/私网(10/8, 172.16/12, 192.168/16)/CGNAT(100.64/10)/链路本地(169.254/16)/文档段(192.0.2/24, 198.51.100/24, 203.0.113/24)/组播(224/4)/保留(240/4)/公网；IPv6 区分未指定/环回/IPv4 映射/IPv4 兼容/文档段(2001:db8::/32)/链路本地(fe80::/10)/组播(ff00::/8)/唯一本地(fc00::/7)/公网
